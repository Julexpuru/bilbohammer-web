# Workflow: Backlog Triage

1. Read `docs/backlog/README.md`.
2. Read `docs/backlog/current.md`.
3. Search existing tasks before creating a new one.
4. Put raw ideas in `inbox.md`.
5. Promote clear work to `tasks/BH-XXX-name.md` using `tasks/_template.md`.
6. Update `current.md` only when project focus changes.
7. Add a short `worklog.md` entry for meaningful backlog changes.

## Task Quality Bar

A task should include:

- Context.
- Scope.
- Acceptance criteria.
- Technical notes.
- Current status.
- Owner.
